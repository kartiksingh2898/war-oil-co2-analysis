# War, Oil & CO2 Analysis (1960–2024)

Live Dashboard:
https://kartiksingh2898.github.io/war-oil-co2-analysis/

---

## Project Overview

This project analyzes the impact of major global wars on global oil prices and CO2 emissions from 1960 to 2024.

The objective is to understand how geopolitical conflicts influence economic trends and environmental changes over time.

---

## Key Features

* Interactive dashboard built using Chart.js
* Time-series analysis (1960–2024)
* Analysis of six major wars
* Correlation between war events, oil price fluctuations, and CO2 emissions
* Clean and responsive interface

---

## Wars Covered

* Vietnam War
* Yom Kippur War
* Iran-Iraq War
* Gulf War
* Iraq War
* Russia-Ukraine Conflict

---

## Key Insights

* Oil prices show significant spikes during major conflicts
* Prolonged wars have extended economic impact
* CO2 emissions continue to rise despite geopolitical instability
* Certain conflicts indirectly influence industrial output
